This is the first submission of GeoIndexR to CRAN.

GeoIndexR provides a flexible framework for computing spectral and
geospatial indices from raster data. The package supports predefined
indices, user-defined mathematical formulas, explicit band mappings,
parameter customization, and reflectance scaling.
